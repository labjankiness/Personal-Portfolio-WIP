Keylogger Detector

Python • Linux Security

What it is

A Linux security scanner that checks a running system for signs of keylogger activity. Runs 8 independent detection checks covering different attack vectors — from user-space process injection to kernel-level rootkits.

Detection checks

  • Process signatures — scans running processes for known keylogger names and patterns
  • LD_PRELOAD hijacking — checks for malicious shared libraries injected via LD_PRELOAD
  • Kernel modules — inspects loaded kernel modules for suspicious names and hidden modules
  • Input device access — identifies processes with open handles to /dev/input devices
  • Persistence mechanisms — checks cron, systemd, .bashrc, .profile for keylogger startup entries
  • Network connections — flags processes reading input devices that also have outbound connections (exfiltration)
  • File system anomalies — looks for suspicious hidden files and log files in unexpected locations
  • X11 hook detection — checks for X11 event grabbing that intercepts all keystrokes
