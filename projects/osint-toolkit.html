OSINT Toolkit

Python • requests • python-whois

What it is

A modular command-line OSINT tool for domain intelligence gathering. Each module can be run independently or all together. Designed for the passive and active reconnaissance phases of a penetration test or security assessment.

Modules

  • WHOIS — registrar, creation/expiry dates, organisation, country, name servers
  • DNS recon — A, AAAA, MX, NS, TXT, CNAME, SOA, SRV records via dig
  • Subdomain enumeration — concurrent wordlist brute-force (50 threads) + certificate transparency logs via crt.sh API (finds subdomains from SSL certificates even without DNS)
  • Google dorks — generates 15 pre-built dork queries (admin panels, config files, exposed credentials, LinkedIn employees, GitHub references) with clickable search URLs
  • Email harvesting — scrapes homepage for email addresses, generates common pattern guesses

Output

Colour-coded terminal output with a summary at the end. Add --report to save everything as a timestamped JSON file for documentation.
