Static Site Generator

Go • No external dependencies

What it is

A minimal static site generator written in Go. Reads Markdown files from content/, applies HTML templates, and outputs a complete static site to public/. Zero external dependencies beyond the standard library (plus one YAML parser for config).

Features

  • YAML frontmatter parsing (title, date, tags)
  • 3 built-in themes: dark, light, minimal — selectable via --theme flag or ssg.yaml
  • Auto-generated RSS feed (feed.xml)
  • Tag index pages — one page per tag listing all posts
  • Live rebuild via --watch flag
  • Built-in dev server via --serve flag

How it works

The Markdown parser is hand-written using only the standard library — no external Markdown library. It handles headings, code blocks with language tags, blockquotes, ordered/unordered lists, inline code, bold, italic, images, and links.
