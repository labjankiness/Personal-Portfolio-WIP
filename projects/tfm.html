Terminal File Manager

Rust • ratatui • crossterm

What it is

A dual-panel TUI file manager for Linux inspired by Midnight Commander and ranger, built in Rust using the ratatui terminal UI library. Designed for keyboard-driven navigation with a preview pane showing file metadata and text content.

Features

  • Dual-panel layout — navigate two directories simultaneously
  • Vim-style navigation (j/k) plus arrow keys
  • File preview pane — shows metadata, first lines of text files
  • File operations: delete, rename, new directory
  • Executable detection with visual indicator
  • Tab to switch active panel

Built with

ratatui for the terminal UI, crossterm for cross-platform terminal input/output. The entire app state is managed in a single App struct with PanelState for each panel.
