Packet Sniffer

Rust • pnet • clap

What it is

A CLI network packet sniffer written in Rust using the pnet library for raw packet capture. Parses packets down to the protocol level and displays them with colour-coded output.

Supported protocols

  • Ethernet frame parsing
  • IPv4 and IPv6 (addresses, TTL, fragmentation)
  • TCP (flags, ports, sequence numbers)
  • UDP (ports, payload length)
  • ICMP (type, code, echo request/reply)
  • ARP (request/reply, MAC to IP mappings)

Features

  • Protocol filtering (--filter tcp, --filter udp, etc.)
  • Port filtering (--port 80)
  • Hex dump mode for raw payload inspection
  • Colour-coded output by protocol type
