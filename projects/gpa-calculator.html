RP GPA/CGPA Calculator

JavaScript • HTML • CSS

What it is

A web-based GPA and CGPA calculator for Republic Polytechnic students. Supports all 41 diploma programmes with their specific module structures. Grade data persists in localStorage so students don't lose their inputs between sessions, and results can be exported as a PDF.

Features

  • All 41 RP diploma programmes supported
  • GPA and cumulative CGPA calculation
  • localStorage persistence across sessions
  • PDF export of results
  • No backend — runs entirely in the browser
