Fracture — Security LLM Research

Python • PyTorch • LoRA • TinyLlama • scikit-learn

Overview

Fracture is a 3-phase self-directed ML research project exploring how machine learning can be applied to cybersecurity — from fine-tuning language models on security data, to building a transformer from scratch, to developing real-world threat detection tools.

Phase 1 — Fine-tuning TinyLlama on Security Data

Base model: TinyLlama-1.1B-Chat-v1.0. Method: LoRA (Low-Rank Adaptation) with r=16 across 6 attention/MLP modules — only 9.9M of 1.1B parameters are trainable. Trained on 634 examples spanning MMLU security questions, CTF writeups, CVE descriptions, and synthetic QA pairs.

The key challenge was dataset quality. Three iterations failed because the MMLU answer texts were 3–10 words long, training the model toward brevity. The fix was replacing all MMLU answers with 100–200 word technical explanations. After that, v4 achieved +5.2 average improvement over baseline across 15 cybersecurity topics, with 10/15 questions improved.

Phase 2 — Transformer from Scratch

Building a small transformer (~0.5M parameters) in pure PyTorch — no HuggingFace, no abstractions. Character tokenizer, causal language model, manual attention implementation. Trained on the same Phase 1 dataset for direct comparison against the fine-tuned model.

Phase 3 — Cybersecurity ML Tools

  • Malware classifier — PE file feature extraction, Random Forest / Gradient Boosting
  • Intrusion detection — CICIDS-2017 network flow classifier
  • Log anomaly detector — Isolation Forest + Autoencoder on auth/Apache logs
  • Vulnerability predictor — C/C++ static analysis with ML
