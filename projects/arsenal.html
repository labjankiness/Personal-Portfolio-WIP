Ultimate CyberSecurity Arsenal

Python • Go • Rust • C • Ollama

Overview

A monorepo of 18+ independent cybersecurity tools built as a hands-on learning platform. Each tool is production-quality with its own CLI, dependencies, and documentation. The repo spans offensive security, defensive tooling, AI-powered threat detection, and security research.

AI & Threat Intelligence

  • Local AI SOC — Full SIEM pipeline using local LLMs (Ollama). Triages alerts, maps to MITRE ATT&CK, runs correlation rules, and serves a Streamlit analytics dashboard. Includes a 27-type attack simulator for testing.
  • Phishing Email Analyzer — Validates SPF/DKIM/DMARC headers, scans URLs for homograph attacks, and uses LLM-based content analysis to flag phishing attempts.
  • AI Phishing Sentinel — Batch CSV phishing detection with structured JSON reports and risk scoring.

Network Security

  • SSH Honeypot — Fake SSH server that captures credentials, attacker commands, and IP geolocation data with real-time Streamlit dashboard.
  • Network Anomaly Detector — Statistical baseline profiling with z-score anomaly detection. Identifies port scans, C2 beaconing, DNS tunneling, and lateral movement.
  • Packet Sniffer — Rust CLI parsing TCP/UDP/ICMP/ARP/IPv4/IPv6 with protocol filtering and hex dump mode.
  • IoT Honeypot — Multi-port monitoring (80, 8080, 554, 23) simulating common IoT services.

Offensive Tools

  • Port Scanner Suite — Same concurrent TCP scanner implemented in Python, C, Go, and Rust. Versions progress from basic → concurrent → CLI → banner grabbing.
  • Web Vulnerability Scanner — Tests for SQL injection (error-based + time-based), reflected XSS, LFI, open redirect, and missing security headers.
  • OSINT Toolkit — Subdomain enumeration (wordlist + crt.sh cert transparency), WHOIS, DNS recon, Google dork generation, email harvesting.
  • Password Cracker — Dictionary + brute-force with leet speak and capitalization mutations across MD5/SHA1/SHA256/SHA512.

Defensive Tools

  • Linux Hardening — UFW, Fail2Ban, SSH hardening, service debloating, with audit mode.
  • Keylogger Detector — 8 detection checks: process signatures, LD_PRELOAD hijacking, kernel modules, persistence mechanisms.
  • Guardian Log Analyzer — SSH auth log parsing with SQLite persistence and IP grouping.
