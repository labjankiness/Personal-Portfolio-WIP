Comms Link Diagnostic Agent

Python • Gemini 2.0 Flash • ReAct Architecture

What it is

A terminal-based AI agent that diagnoses network signal quality using the ReAct (Reasoning + Acting) architecture. Given a signal scenario, the agent reasons about what to check, calls diagnostic tools, interprets the results, and produces a structured diagnosis — mimicking how a network engineer would think through the problem.

ReAct loop

The agent operates in a think-act-observe cycle: it reasons about the current state, decides which tool to call, observes the result, and updates its reasoning. This continues until the agent has enough information to produce a final diagnosis. The full reasoning trace is printed so you can see exactly how it arrived at its conclusion.

Tools

  • analyze_signal_metrics — evaluates SNR, RSSI, noise floor, and modulation scheme against thresholds
  • check_bandwidth — calculates theoretical and effective throughput given current conditions
  • trace_route_analysis — analyses latency and packet loss patterns across network hops
