SSH Honeypot

Python • Socket • SQLite • Streamlit

What it is

A fake SSH server that listens on port 22, accepts connections, and captures everything attackers do — without giving them real access to anything. Built to study real-world attack patterns and credential stuffing in the wild.

What it captures

  • All connection attempts with timestamps and source IPs
  • Username/password combinations tried (credential capture)
  • Commands entered after fake login acceptance
  • IP geolocation (country, city, ASN)
  • Credential reuse detection across multiple IPs

Analytics

All data is persisted in SQLite and visualised in a Streamlit real-time dashboard showing attack frequency, top credentials tried, geographic heatmap of attackers, and automated attack pattern analysis. The honeypot also flags when the same credential pair is tried from multiple IPs — a strong indicator of a credential stuffing campaign.
