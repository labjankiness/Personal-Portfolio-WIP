Network Anomaly Detector

Python • Statistics • Streamlit

What it is

A statistical anomaly detection engine for network traffic. Instead of using fixed rules, it builds a behavioral baseline from observed traffic patterns and flags deviations using z-score analysis — the same approach used in real SOC environments.

What it detects

  • Port scans — unusually high connection attempts across many ports from one source
  • C2 beaconing — regular, periodic outbound connections (fixed interval = automated)
  • Data exfiltration — abnormally large outbound data volumes
  • DNS tunneling — high DNS query frequency or unusually long domain names
  • Lateral movement — internal hosts scanning other internal hosts

How the baseline works

The engine collects traffic statistics over a configurable window, calculates mean and standard deviation per metric per source, and flags any observation more than N standard deviations from the mean. The Streamlit dashboard shows live traffic, active anomalies, and baseline drift over time.
