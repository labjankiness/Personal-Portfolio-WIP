Port Scanner Suite — 4 Languages

Python • C • Go • Rust

What it is

The same concurrent TCP port scanner implemented four times — in Python, C, Go, and Rust — to compare concurrency models, performance, and developer ergonomics across languages. Each implementation progresses through 4 versions: basic → concurrent → CLI → service banner grabbing.

Language comparison

  • Python — ThreadPoolExecutor, simplest code, slowest execution
  • C — pthreads, fastest raw performance, most manual memory management
  • Go — goroutines + channels, excellent balance of speed and readability
  • Rust — Rayon parallel iterators, memory-safe, near-C performance

A separate benchmarking tool auto-compiles all versions, runs each against the same target, and generates a comparative report with timing data and tradeoff analysis.
