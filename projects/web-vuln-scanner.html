Web Vulnerability Scanner

Python • requests • BeautifulSoup

What it is

A Python CLI tool that tests web applications for common vulnerabilities by injecting payloads into URL parameters and analysing responses. Supports single-URL scanning or full site crawling.

Checks

  • SQL Injection — error-based detection (SQL error strings in response) and time-based blind (SLEEP payload with response delay measurement)
  • Reflected XSS — injects script payloads and checks if they appear unencoded in the response
  • Local File Inclusion — path traversal payloads checking for /etc/passwd and Windows hosts file signatures
  • Open Redirect — tests redirect parameters (url=, next=, return=) for external redirect hijacking
  • Missing Security Headers — checks for CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy

Usage

python scanner.py "http://target.com?id=1" — scan a single URL. Add --crawl to spider the site and test all discovered parameters. Add --report to save a JSON report.
