Local AI SOC Agent

Python • Ollama • SQLite • Streamlit • MITRE ATT&CK

What it is

A self-hosted Security Operations Center that uses locally-running LLMs (via Ollama) to automate alert triage — no cloud APIs, no data leaving the machine. Designed to demonstrate how AI can assist a SOC analyst rather than replace them.

Pipeline

  • Ingestion — accepts security alerts in JSON format (simulated or real)
  • Triage — LLM classifies severity, identifies attack type, and generates a structured analysis with confidence score
  • MITRE mapping — maps each alert to relevant ATT&CK techniques and tactics
  • Correlation — groups related alerts across time windows to surface attack campaigns
  • Response engine — suggests remediation steps based on the identified technique
  • Persistence — all alerts and analyses stored in SQLite for historical analysis

Testing

Includes a 27-type attack simulator that generates realistic alert payloads for: brute force, SQL injection, XSS, port scans, privilege escalation, lateral movement, data exfiltration, ransomware, and more. Used to validate detection logic without needing a real compromised environment.
