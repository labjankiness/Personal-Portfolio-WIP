ZephyrOS — AI-Powered Linux Distribution

Shell • Linux • archiso • Wayfire • Ollama

What it is

ZephyrOS is a standalone Linux distribution built on Arch Linux. Unlike most distros that require post-install setup, ZephyrOS ships with a locally-running AI model pre-configured out of the box — no internet required for AI features after install.

5 Editions

  • Scholar — educational focus, general-purpose AI assistant
  • Dev — development tools, code generation model
  • SOC — security operations, threat analysis tools pre-installed
  • Lite — minimal footprint, lightweight AI model
  • Core — base system, no AI bundle

Technical details

Built using archiso, Arch's official live media creation tool. Each edition is configured via a profile directory specifying packages, services, and custom scripts. The Wayfire Wayland compositor provides the desktop environment. A guided TUI installer (based on archinstall) handles partitioning, user creation, and bootloader setup with full UEFI support.

AI models are bundled via Ollama and auto-start on boot as a systemd service, making them available immediately after login.
