FPS Protocol

JavaScript • Three.js • WebGL

What it is

A 3D first-person shooter training range that runs entirely in the browser using Three.js and WebGL. No download, no install — just open and play. Built to explore 3D game development fundamentals: scene management, raycasting, collision detection, and game loop design.

Features

  • 3D environment with first-person camera controls (pointer lock)
  • Multiple game modes with varying difficulty
  • Moving targets with different movement patterns
  • Score tracking and performance metrics
  • Adjustable sensitivity and settings

Technical notes

Hit detection uses Three.js raycasting — a ray is cast from the camera in the look direction on each click, and intersection tests determine hits. Target movement is driven by parametric equations to create smooth, unpredictable patterns without a physics engine.
