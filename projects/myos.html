MyOS — Bare-Metal x86 Operating System

C • x86 Assembly • GRUB • Systems Programming

What it is

MyOS is a fully bootable x86 operating system built from scratch — no Linux, no POSIX, no standard library. It boots via GRUB into an 800x600 graphical desktop and runs entirely on bare hardware (or QEMU). Everything from the memory allocator to the window manager to the TCP/IP stack is hand-written in C and x86 Assembly.

Features

  • Windows 7-style GUI with draggable windows, taskbar, start menu, and system clock
  • 14 built-in applications: Notepad, Calculator, System Info, Terminal, File Manager, Breeze Browser, Paint, Snake, Minesweeper, Tetris, 2048, Flappy Bird, Solitaire, Checkers
  • 50+ terminal commands (ls, cat, mkdir, ping, ifconfig, etc.)
  • Persistent filesystem with file manager and app launching
  • Networking stack (IPv4, TCP, UDP, ICMP, ARP, DHCP)
  • Preemptive multitasking via PIT timer interrupts
  • PC speaker sound system
  • AI assistant integration via local LLM

How it boots

boot.asm sets up the GDT, loads the IDT, installs ISR/IRQ stubs, and jumps to kernel_main in C. The kernel then initializes the PIT timer at 100Hz, sets up PS/2 keyboard and mouse drivers via interrupt handlers, allocates heap memory with a simple free-list allocator, and enters the desktop event loop.

The framebuffer is set up by GRUB using VESA mode 0x118 (800x600x32). All rendering goes directly to video memory — there's no GPU driver, just pixel writes.

The window manager

The WM uses a simple back-to-front painter's algorithm: draw the desktop background, then each window in z-order, with the active window on top. Dragging is handled by tracking mouse delta between frames and updating the window's position. Each app receives keyboard and mouse events via a per-window message queue.

What I learned

Building MyOS forced a deep understanding of things that are normally invisible — how interrupts actually work, what the CPU does on a context switch, why virtual memory exists, how TCP segments are assembled from raw Ethernet frames. There's no abstraction to hide behind when you wrote everything yourself.
